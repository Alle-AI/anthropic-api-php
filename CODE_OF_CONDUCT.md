# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be inclusive, and assume good faith. Harassment, discrimination, and personal attacks are not tolerated.

To report violations, email [dickson@alle-ai.com](mailto:dickson@alle-ai.com). Reports are kept confidential.

The full Contributor Covenant text is available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
